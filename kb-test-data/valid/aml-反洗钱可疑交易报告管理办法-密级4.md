# 一、总则
本行根据《反洗钱法》及人民银行相关规定，对可疑交易履行识别、报告义务。

# 二、可疑交易特征
## 2.1 资金交易类
- 短期内分散转入、集中转出，金额接近大额交易标准。
- 账户资金快进快出，交易频率与客户身份不符。

## 2.2 账户行为类
- 长期不动户突然发生大额交易。
- 客户拒绝提供资金来源或用途说明。

# 三、报告流程
## 3.1 识别上报
网点人员发现可疑线索后，2 个工作日内填制《可疑交易报告》，报送反洗钱中心。

## 3.2 中心复核
反洗钱中心复核后，在法定期限内通过反洗钱监测系统向人民银行提交报告。

# 四、保密要求
可疑交易报告相关内容严格保密，严禁向客户或无关人员泄露调查信息。
