# 一、总则
为规范员工职业行为，营造廉洁合规的工作氛围，制定本细则。

# 二、考勤管理
## 2.1 工作时间
标准工作时间为周一至周五 9:00-17:30，柜面岗位按排班执行。

## 2.2 请假流程
年假、事假须提前 3 个工作日在 OA 系统提交申请，经直属主管审批。

# 三、廉洁要求
1. 严禁收受客户财物，包括现金、礼品、卡券等。
2. 严禁利用职务便利为亲属或他人谋取不当利益。
3. 发现违规行为应及时向纪检监察部门报告。

# 四、保密义务
员工对工作中知悉的客户信息、经营数据负有保密义务，离岗后保密义务依然有效。
