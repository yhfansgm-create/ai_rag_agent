# 一、总则
为规范全行信贷审批授权管理，明确各级审批权限边界，防范信贷风险，制定本办法。

# 二、审批权限层级
## 2.1 支行权限
支行行长对单户授信金额 500 万元（含）以下、且风险评级为 A 类的客户拥有审批权。

## 2.2 分行权限
分行信贷审批部对单户授信金额 500 万至 5000 万元（含）、风险评级 B 类及以上的客户拥有审批权。

## 2.3 总行权限
总行信贷管理委员会对单户授信金额超过 5000 万元，或涉及关联集团客户、跨境融资的授信拥有最终审批权。

# 三、风险评级标准
风险评级分为 A/B/C/D 四级，由风险管理部门依据客户财务状况、担保能力、历史还款记录综合评定，评级结果每年复审一次。

# 四、授权限制
1. 各级审批权限不得擅自转授。
2. 关联企业授信须合并计算，防止分拆规避权限。
3. 逾期贷款重组、核销须报总行信贷管理委员会审批。
