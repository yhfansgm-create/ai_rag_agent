# 一、产品概述
本行代理销售投资金条、工艺金及贵金属积存业务，销售遵循"卖者尽责、买者自负"原则。

# 二、销售流程
## 2.1 客户确认
销售人员须向客户充分揭示贵金属价格波动风险，客户签字确认《风险揭示书》。

## 2.2 交易执行
按当日挂牌金价执行交易，成交后出具交易凭证。

# 三、售后说明
支持回购业务，回购价格按回购日挂牌金价减回购价差执行，具体以网点公示为准。
