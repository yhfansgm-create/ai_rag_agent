# 一、产品概述
本行推出的"智存宝"智能存款产品，面向个人客户，支持整存整取、通知存款、定活两便三种形态。

# 二、产品要素
## 2.1 起存金额
个人客户起存金额为 100 元人民币，单笔最高 500 万元。

## 2.2 利率档次
| 期限 | 年利率 |
|------|--------|
| 3个月 | 1.25% |
| 6个月 | 1.45% |
| 1年   | 1.65% |
| 3年   | 2.10% |

# 三、计息规则
1. 按实际存款天数计息，活期部分按挂牌利率。
2. 提前支取按支取日活期挂牌利率计息。
3. 到期自动转存，转存期与上期相同。

# 四、办理渠道
本产品可通过柜面、手机银行、网上银行等渠道办理，具体以各渠道展示为准。
