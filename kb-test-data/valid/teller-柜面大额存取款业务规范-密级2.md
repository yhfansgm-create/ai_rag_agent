# 一、适用范围
本规范适用于各营业网点柜面大额现金存取款业务，柜员须严格遵照执行。

# 二、大额标准
单笔取现 5 万元（含）以上、单笔存款 20 万元（含）以上，即构成大额交易，须启动授权流程。

# 三、授权流程
## 3.1 柜员操作
柜员在核心系统录入交易，系统提示"大额交易需授权"后，不得自行确认。

## 3.2 主管授权
网点运营主管通过授权终端复核客户身份证件、账户余额及交易用途后，方可放行。

## 3.3 授权记录
授权过程须留存影像与日志，包括：授权人、授权时间、客户证件号、交易金额。

# 四、客户身份核验
客户须出示有效身份证件原件，柜员通过联网核查系统验证证件真伪及信息一致性。代办业务须额外核验代办人证件并登记。

# 五、异常处理
- 证件信息与账户不符：拒绝办理并登记。
- 系统授权超时：重新发起交易，严禁绕过授权直接提交。
- 客户行为异常（频繁存取、神色异常）：上报运营主管并视情况启动可疑交易报告流程。
