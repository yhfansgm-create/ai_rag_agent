# 一、说明
本文档为 2023 年版自助设备操作规程，已由《自助设备管理新规》替代，本版本自 2025-04-30 起废止。检索时请注意引用当前有效版本。

# 二、ATM 加钞
加钞须双人双锁，加钞前后均须清点现金并登记《加钞登记簿》。

# 三、设备故障处理
设备发生吞卡、吐钞异常时，柜员按故障流程登记工单并联系维保厂商，严禁私自打开机箱。
