# 一、大额取款标准

单笔或当日累计取现 10 万元（含）以上为大额取款。

# 二、授权要求

大额取款须经网点主管与值班经理双人授权后方可办理。

# 三、登记要求

经办人员应在《大额现金支取登记簿》登记客户身份信息、资金用途及反洗钱风险等级。

# 四、过渡安排

本规范自 2025 年 1 月 1 日起施行，原《柜面大额取款业务规范》（1.2 版）同时废止。
